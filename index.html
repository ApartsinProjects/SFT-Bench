Semantics Gate, Statistics Decide: Predicting Zero-Shot Transfer to Unseen Sensors from Source Data Alone

Abstract

When a new sensor is added to a monitored system, a model has no history for it and normally needs fresh labeled data to use it. We ask whether a semantic embedding of the sensor, derived from its name, units, and role, lets a shared encoder predict the new sensor from the others with little or no target data, and we characterize exactly what such an embedding contributes. Studying zero-shot sensor imputation on the Tennessee Eastman Process under a strict, leakage-controlled protocol, we find that realized skill decomposes cleanly: the magnitude of what a model can predict is fixed by the statistical recoverability of the sensor from its same-type siblings, and is the same for any embedding, while the semantic embedding contributes the polarity of the prediction. A source-only signed-recoverability statistic, computable before any target label, predicts realized zero-shot skill with rank correlation 0.73, and it predicts the failures as well as the successes: sensors whose siblings are anti-correlated receive a confident wrong-sign prediction. Because semantics buy the sign rather than the magnitude, the labeled-data saving is small and precise, about one to two target samples, concentrated at the zero-shot point. A discriminative text embedding is required, as coarse one-hot metadata confidently mislabels sensors it cannot tell apart. We also give a runnable admission test that screens whether a dataset can exhibit the effect at all, and show the same recoverability rule dissociates a temperature sensor that transfers in a building dataset from one that does not in the process dataset.

1. Introduction

A model knows the numbers a sensor produces, but not what the sensor means, so a newly installed sensor starts cold.

Adding a sensor to an industrial plant, a building, or a monitored process is common, and the model that watches the plant has no history for the new channel. The conventional response is to collect and label new data for it. Recent work on schema-flexible and foundation tabular models shows that column text or metadata can help a model reuse knowledge across features, yet time-series foundation models remain largely metadata-blind, and it is unclear how much external sensor semantics actually buy, and under what conditions. We study this directly and give a quantitative account.

Our object of study is a shared encoder that processes every sensor conditioned on a semantic embedding of that sensor, so behaviour learned for one sensor can apply to a new sensor whose embedding is close. The question is not whether semantics help on average, which prior work established, but what specific quantity they contribute, whether that contribution is predictable in advance, and when it fails.

This paper contributes: a decomposition of zero-shot transfer skill into a magnitude set by statistics and a polarity set by semantics; a source-only signed-recoverability statistic that predicts realized transfer, including its failures, before any target label; a measurement of the resulting labeled-data saving, which is small and localized to the sign; the finding that a discriminative text embedding is necessary because coarse metadata confidently mislabels indistinguishable sensors; a runnable dataset-admission test; and a cross-domain dissociation showing the rule tracks statistics, not the semantic label.

2. Setup and protocol

We study zero-shot imputation of an unseen sensor. A held-out sensor is removed from every training input and is never a training target; a query-conditioned cross-attention model imputes it at test time from the other sensors and its semantic embedding, so the embedding determines which context sensors the model attends to. We use the Tennessee Eastman Process, whose fifty-two variables carry clear measurement semantics (pressures, temperatures, levels, flows, compositions, and manipulated valves). Evaluation splits are leakage-controlled: training uses each fault type's simulation run and testing uses the same fault type's independent run, so cross-sensor relationships hold while the trajectories are distinct. A train-query probe confirms the task is learnable on the test trajectories (tracking skill 0.25); an earlier disjoint-fault split failed this probe and made the effect spuriously vanish.

The metric is tracking skill, the correlation between the predicted and true series of the held-out sensor. We report it three ways, because pooling correlation over several operating regimes conflates identifying the regime with tracking within it: the magnitude \(|r|\), the sign-consistency across seeds, and the within-run correlation. Embeddings are compared inside one fixed architecture; only the per-sensor embedding changes.

3. The decomposition: magnitude from statistics, polarity from semantics

Per seed, the magnitude \(|r|\) a model extracts for a given sensor is nearly fixed, while its sign varies. A random embedding recovers the same correlation with a held-out pressure sensor as a semantic one; it simply cannot decide the polarity. Define the source-only signed recoverability of sensor \(j\) as the correlation of \(j\) to its best same-type sibling, measured on training data with the sign kept. Across held-out sensors:

The signed-recoverability statistic predicts realized zero-shot skill from source data alone, before any target label. It is not merely a success predictor: sensors whose same-type siblings are anti-correlated receive a confident wrong-sign prediction, which the signed statistic forecasts as a negative skill. A manipulated valve whose nearest same-type sibling moves oppositely is imputed with skill near its negative sibling correlation, exactly as predicted.

4. The failure mode: sign-blind transfer, and why text beats metadata

Zero-shot semantic imputation is sign-blind: the embedding selects which siblings to attend to and the model reproduces their signed correlation, so an anti-correlated eligible sibling yields a confident wrong answer. This makes the choice of embedding consequential in a specific way. One-hot metadata that assigns identical descriptors to several same-type sensors cannot tell them apart, so it attends to the wrong sibling and locks the wrong sign; a text embedding that carries the distinguishing name attends correctly.

Compositions share their one-hot metadata with several sensors and the two cooling temperatures share theirs with each other, so metadata confidently imputes them with the wrong sign while text does not. Consequently the signed-recoverability law holds for the text embedding (Spearman 0.73) and is weak for one-hot metadata (0.32), and within-run tracking, which measures real tracking rather than regime identification, is much higher for text (0.44 on recoverable sensors versus −0.01 on non-recoverable ones).

5. What the embedding saves: about one label, at the sign

Because magnitude is statistical and polarity is semantic, the labeled-data benefit is small and localized. We cold-start a held sensor by adapting its embedding on \(K\) target samples, starting either from the text embedding or from a fresh random vector, and measure skill against \(K\). At \(K=0\) the semantic start gives the correct-polarity prediction (mean signed skill +0.59, correct sign in 83% of seeds) while the fresh start is a coin flip (\(-0.17\), 58%); on the strongest sensor the gap is +0.91 against \(-0.45\). By \(K=2\) the fresh start has learned the sign from the samples and matches the semantic start. The magnitude \(|r|\) is identical for both starts at every \(K\), as the decomposition predicts.

The practical statement is therefore precise rather than inflated: knowing the sensor's semantics buys the zero-shot and first-sample regime, roughly one to two labeled observations, not a large reduction in total training data. What it buys is exactly the quantity the statistics cannot supply, the sign.

6. Admissibility and cross-domain generality

A dataset can exhibit this effect only if some target is recoverable from features that are held out with it. We screen datasets with a headroom gate: hold a fault's primary sensors out and measure whether detection degrades. A single-duct air-handling-unit fault-detection benchmark fails the gate, because closed-loop control propagates every fault across the sensor set and leaves no sensor necessary; the Tennessee Eastman Process passes it. Separately, fault detection proves value-evident, a value-only model detects a held-out fault at AUROC 0.94 with the fault's columns masked in training, so it cannot exhibit semantic feature transfer, which is why the transfer experiments use imputation.

The recoverability rule tracks statistics rather than the semantic label, and this dissociates the same measurement type across domains. In a building dataset, temperature sensors are strongly cross-correlated (sibling correlation 0.6 to 0.97), so the rule predicts they transfer; in the process dataset, several temperatures are independently controlled to setpoints (sibling correlation 0.06), so the rule predicts they do not. Same type, opposite recoverability, opposite predicted outcome, from a statistic computable without any model.

7. Related work

Feature-metadata transfer for tabular data is established in static tables. CARTE pretrains a graph-attention model over tables using column names, and TransTab and XTab transfer across tables with overlapping-but-different schemas; TabLLM serializes column names for large language models; TabPFN attains sample efficiency without column metadata and is a strong metadata-free reference. In clinical learning, GRAM uses an ontology of codes to improve prediction for rare features, the closest precedent for ontology metadata buying sample efficiency. Inductive spatio-temporal kriging predicts a new sensor from its location, and content-based cold-start recommenders substitute metadata for interaction history. Against this, current time-series foundation models are largely metadata-blind. Our contribution is not that metadata helps, but a quantitative account of what it contributes (polarity, not magnitude), a source-only predictor of when it helps and when it harms, and the admission and dissociation results that separate the semantic label from the statistics that actually govern transfer.

8. Discussion

The results give a deployment rule. Before commissioning a new sensor, compute the signed recoverability of its semantic class from existing data: a large positive value means a shared semantic model can predict it at once; a value near zero means there is no borrowable signal; a negative value means semantics will confidently produce the wrong sign, so the sensor should not be virtualized zero-shot without at least one observation to fix the polarity. The embedding must be discriminative enough to distinguish same-type sensors, which text descriptions provide and coarse categorical metadata does not. The limitations are plain and stated as scope: the transfer measurements are on one process dataset with a simulation origin, the admission and dissociation results add a second domain only at the level of the statistic, and the labeled-data saving, while real and predictable, is localized to the sign. These boundaries are what the source-only statistic is for.

9. Conclusion

Semantic descriptors decide where a zero-shot imputer looks; the signed correlation structure of what it finds there decides what it achieves. Both are computable from source data before any target label. Semantics contribute polarity and statistics contribute magnitude, realized skill equals signed recoverability, and the failures are predicted rather than merely observed. The practical value is a pre-deployment test that says whether, and how, external sensor semantics will help a new variable.
