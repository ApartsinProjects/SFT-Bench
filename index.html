Abstract

Predictive models usually treat input features as anonymous dimensions. A model may learn extensively from a feature such as reactor pressure, yet it has no mechanism for reusing that knowledge when a semantically related feature appears, such as separator pressure. We study whether representing each numerical feature together with a semantic embedding derived from a domain knowledge graph lets a model reuse predictive behaviour across related features, so that new sensors and variables need fewer labeled examples. We formalise this as semantic feature transfer and introduce SFT-Bench, a cross-domain benchmark with a construct-matched protocol: the architecture, splits, and seeds are held fixed and only the semantic embedding varies, under pre-registered invariants that separate a semantic effect from an architectural one. We report three findings. First, a dataset can test the hypothesis only when fault evidence is feature-localized and non-redundant; a runnable admission gate shows that a common HVAC benchmark fails this test while the Tennessee Eastman Process passes it. Second, the task matters: fault detection is value-evident and cannot exhibit the effect, whereas on zero-shot sensor imputation a semantic embedding lets the model predict a sensor it was never trained to predict, with correct semantics beating a shuffled-semantics control in five of five seeds and pressure sensors tracked at correlation 0.92. Third, semantic similarity alone does not predict transfer gain (Spearman 0.06); transfer is governed by the statistical predictability of same-type siblings.

1. Introduction

Models know the numerical values of their features but usually do not know what those features mean.

A conventional model ties the identity of each feature to a fixed input position and learns a mapping \( f(x_1,\ldots,x_m)\rightarrow y \). When a new but related feature is introduced, that model sees only a new anonymous column and must learn its behaviour from target data alone, even when it has already learned a great deal from a feature that measures the same physical quantity on a related component. We call the resulting problem the new-feature cold-start: a feature whose meaning is known from a domain ontology but whose predictive behaviour has not yet been observed.

External domain knowledge offers a way in. A knowledge graph that states a sensor measures pressure, is located at a separator, and is part of a process system places that sensor near others that share those properties. If a model is organised so that its per-feature computation is keyed on such semantics rather than on column position, then behaviour learned for one feature can apply to a semantically neighbouring feature that the model has never seen during training.

This work contributes: a formalization of semantic feature transfer and a label-efficiency measure for it; a construct-matched evaluation protocol in which only the semantic embedding varies, with pre-registered invariants; a benchmark-admission gate that identifies which datasets can test the hypothesis at all, and the finding that a common HVAC benchmark cannot while the Tennessee Eastman Process can; and evidence that semantic embeddings enable zero-shot sensor imputation, together with the boundary conditions on when they do, including that semantic similarity does not by itself predict transferability.

2. Problem definition

We represent a sample not as a bare vector but as a set of semantically described measurements, \[ X = \{(x_j, e_j)\}_{j=1}^{m}, \] where \(x_j\) is the observed value or short temporal window for feature \(j\) and \(e_j\) is a semantic embedding derived from a domain ontology. A shared feature encoder maps every pair to a representation \[ z_j = F_\theta(x_j, e_j), \] the encoded features are combined by a permutation-invariant aggregator \( z = A(z_1,\ldots,z_m) \), and a head predicts \( \hat y = G(z) \). Because the same \(F_\theta\) processes every feature, the model can learn rules associated with semantic concepts rather than with fixed columns. For a previously unseen feature \(j^{*}\), an embedding \(e_{j^{*}}\) is generated from its ontology neighbourhood, so the encoder produces a representation for it without ever having seen its identity during training.

We measure the contribution in terms of label efficiency rather than absolute accuracy. Let \(K_M(q)\) be the number of labeled target examples model \(M\) needs to reach performance \(q\). Semantic transfer efficiency is \[ \mathrm{STE}(q) = \frac{K_{\text{baseline}}(q)}{K_{\text{semantic}}(q)}, \] so an \(\mathrm{STE}(q)\) of five means the semantic model reaches performance \(q\) with one fifth of the target labels the baseline requires. The zero-shot results in Section 7 correspond to the limit \(K_{\text{semantic}}=0\): the semantic model reaches nonzero skill with no target labels at all.

3. Method

The semantic embedding \(e_j\) is the object under study, so the method is defined as a family of embedding sources evaluated inside one fixed architecture. We consider a random embedding (a fixed vector per feature), a learned per-feature identity embedding, a text embedding of the feature name, unit, and component description, a metadata embedding of measurement type, component type, and unit without graph topology, and a knowledge-graph embedding constructed from the feature's ontology neighbourhood: a relation-typed encoding of the node's typed edges (measures, is-located-at, is-part-of), so an unseen feature node receives an embedding directly from its relations without any training on the graph.

4. SFT-Bench

SFT-Bench evaluates the same method across independent domains rather than across splits of a single dataset. Each domain contributes labeled data, an independent ontology, and common transfer protocols under one unified representation, so datasets with different feature counts share the same architecture.

5. Evaluation protocol

The protocol is construct-matched: across every condition the temporal encoder, the shared feature encoder, the aggregator, the head, the splits, and the seeds are identical, and only the embedding \(e_j\) changes. Embeddings are padded to a common dimension so that no condition receives more parameters than another, and every comparison is computed in a single pass and saved as one artifact. The conditions are summarised below.

Two comparisons decide the central question. Knowledge-graph against text tests whether explicit graph structure adds value beyond what a modern text encoder already captures from the same metadata. Correct-graph against shuffled-graph, on an identical architecture, tests whether any benefit is semantic rather than a by-product of the shared encoder. The protocol carries pre-registered invariants whose expected outcomes are stated before each run: a degenerate value-only model matches a plain fixed-column model on full data; performance is non-decreasing in the number of target labels; in aggregate across queries and seeds, the correct graph is at least as good as the shuffled graph, which is at least as good as the random embedding; and the learned-identity condition cannot succeed at zero-shot on a held-out feature. A violated invariant is treated as a defect to locate rather than a result to report.

The protocol defines a common experiment ladder per domain: full-data prediction, few-shot feature transfer as a function of the number of target labels \(K\), zero-shot feature cold-start, component cold-start, and cross-dataset transfer. This paper reports the zero-shot rung, which isolates the semantic effect most sharply. Because fault detection is value-evident (Section 7.1), the transfer measurements are made on zero-shot sensor imputation: a held-out query sensor, never a training target, is predicted from the other sensors and its semantic embedding through query-conditioned cross-attention, so a semantic embedding that places the query near its trained siblings can transfer their learned prediction behaviour.

6. Semantic-distance analysis

Beyond aggregate accuracy, the benchmark tests whether semantic distance predicts transferability. For each feasible source-target feature pair we compute a semantic similarity \(S_{ij}=\operatorname{sim}(e_i,e_j)\) and an empirical transfer gain \[ T_{ij} = \mathrm{Performance}_{\,i\rightarrow j} - \mathrm{Performance}_{\,\text{scratch}(j)}, \] and examine \(\mathrm{corr}(S_{ij}, T_{ij})\). A positive relationship would support the deeper claim that semantic similarity predicts statistical transferability. Section 7.3 reports the measured relationship on the Tennessee Eastman Process.

7. Results

7.1 Benchmark admissibility

The admission gate holds out a fault's primary sensor columns and measures whether detection degrades. On the LBNL single-duct air handler, masking a fault's own columns leaves detection essentially unchanged, because closed-loop control propagates every fault across the sensor set and no column is necessary; the drop is within noise of zero. On the Tennessee Eastman Process the same gate produces large drops for the reactor-cooling faults, whose evidence is concentrated on the cooling-loop sensors. Fault detection additionally proves value-evident: a value-only model detects a held-out fault at AUROC 0.94 with the fault's columns masked during training, because an anomalous value is anomalous regardless of feature meaning. Fault detection therefore cannot exhibit semantic feature transfer, and the transfer experiments use zero-shot sensor imputation, where the model must produce an unseen sensor's value and cannot sidestep its meaning.

7.2 Zero-shot imputation transfer

A held-out query sensor is predicted from the other sensors and its semantic embedding through query-conditioned cross-attention; the query was never a training target. Transfer is measured as tracking skill, the Pearson correlation between the predicted and true series of the held-out sensor. This bounded metric is stable when normal and fault regimes are pooled, where \(R^2\) is dominated by regime shifts in the denominator. Across ten held-out queries spanning six measurement types and five seeds, correct semantics beat a shuffled-semantics control in every seed (metadata tracking skill 0.153 against a shuffled control at -0.006, paired difference +0.159, positive in 5 of 5 seeds). The effect concentrates where same-type siblings are predictive (sensors of the same measurement type that were training targets): an unseen stripper pressure, related through its embedding to the reactor and separator pressures, is tracked at 0.92, while flows and levels do not transfer and temperature is mixed across embedding sources. The shuffled control retains partial skill on pressure (0.47) because several pressures are mutually predictive under any query embedding, and the correct embedding still nearly doubles it.

No single embedding source dominates across types: measurement-type metadata carries most of the usable semantics here, and the knowledge-graph embedding does not provide a consistent advantage over it on this process, which localizes the value of explicit topology to settings this benchmark can now identify.

7.3 Semantic similarity does not predict transferability

Across held-out queries, the semantic similarity of a query to its nearest same-type sibling shows no rank correlation with its realized transfer (Spearman 0.06). Sensors with identical semantic embeddings transfer very differently, and a sensor with modest similarity to its siblings can transfer best. Transfer is governed by whether the same-type siblings are statistically predictive of the query, not by semantic proximity alone, which indicates that similarity must incorporate operating regime and causal structure to track transfer, and bounds the claim that graphs can be read for transferability directly.

8. Related work

The approach connects transfer learning and tabular transfer, schema and entity matching, knowledge-graph embeddings and inductive graph learning, set and feature-token architectures, metadata-aware and ontology-informed models, and the application literatures of industrial fault diagnosis and cross-dataset clinical prediction. The distinguishing element here is the combination of a training-free ontology-derived embedding with a shared, position-free feature encoder evaluated for label efficiency across independent ontologies.

9. Conclusion

External semantic knowledge acts as a prior over feature identity, letting a model predict an unseen sensor it was never trained to predict when that sensor's semantic siblings are informative. The effect is strongest for pressure sensors and beats a shuffled-semantics control in every seed. It is also bounded: it requires a task that is not value-evident, it concentrates where same-type siblings are statistically predictive rather than merely semantically close, and explicit graph topology does not improve on measurement-type semantics on this process. SFT-Bench, its construct-matched protocol, and its admission gate provide the apparatus to measure these conditions, and to say cleanly when semantic feature transfer helps and when it cannot.
